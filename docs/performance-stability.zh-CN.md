# 性能与稳定性说明

稳定版核心范围、手动测试清单、支持边界和长期维护策略见
[STABILITY.md](STABILITY.md)。

## 自动化稳定性门禁

- `npm run lifecycle:check` 会在强制 GC 下分别对 DOCX、PPTX、XLSX 和混合
  顺序执行 100 次打开/重载/导航/切换/关闭循环，并门禁 Blob URL、缓存、
  任务、定时器、观察器、监听器、过期 UI 提交、保留堆趋势、可恢复包错误和
  未处理 rejection。完整 JSON、精简趋势点和 Markdown 摘要会写入
  `benchmark-results/`，CI 保存 90 天。
- `npm run performance:check` 以五个独立进程运行快速 CI 样本；
  `npm run large-files:extended` 以三个独立进程覆盖 500 页 DOCX、
  2,000 页 PPTX、Excel 行上限稀疏 XLSX 和 50,000 行/400,000 单元格稠密
  XLSX。扩展门禁每周及发布前运行，不拖慢每次提交，并输出同结构的机器可读
  趋势产物。

## 共享架构与运行时策略

- DOCX DOM 提交、PPTX 元数据/缩略图任务和 XLSX 流式解析共用自适应 8 ms
  工作切片策略；前台导航可抢占后台工作，内存压力升高时降低批次与并发，达到
  临界压力时停止预加载并释放非活动缓存。
- 共享阅读壳层以及 `OfficeReaderAdapter`、`ReaderSession`、
  `ReaderCapabilities` 契约统一工具栏、状态、错误、诊断与资源清理行为；
  DOCX/PPTX/XLSX 渲染逻辑分别位于格式专属适配器和会话。
- 持久化设置带显式 schema 版本，并按 `common`、`docx`、`pptx` 和 `xlsx`
  分区；2.4 之前的扁平设置会自动迁移。损坏或部分写入的数据会按字段回退；
  原始读取失败后不会被自动修复写入覆盖。
- 文件修改、删除、重命名或工作区恢复格式不匹配时，会在过期解析、搜索、
  缩略图、工作表、绘图或 DOM 工作提交前使当前代次失效；合法重复视图彼此
  隔离，不会阻止启动。
- 渲染流程同时使用取消 token 和文件代次，过期结果会被丢弃。
- 生产构建强制执行 `dist/main.js` 不超过 500 KiB 的体积预算。
- 阅读状态使用最多保留 100 个文件的 LRU 存储；每条记录只包含路径、修改
  时间、格式、位置、缩放和导航状态。源文件修改后会清除过期的位置与导航
  状态，同时保留用户的缩放与适配偏好。
- 关闭或卸载文件时会释放文档缓冲、生成的 Blob URL、搜索定时器和搜索结果
  引用。

## 各格式运行时行为

- PPTX 文件读取和幻灯片渲染使用独立的取消代次，快速切换文件或页码时
  不会提交过期画面。
- PPTX 当前页会在全量元数据索引完成前开始渲染；后台元数据解析可取消，
  且最多使用四个并发 worker。
- 演示文稿搜索复用预计算的规范化索引；导航列表最多同时挂载 60 行，
  缩略图渲染最多使用两个低优先级 worker。
- 离开可视区域的缩略图会被卸载并释放生成的图片资源；过期的幻灯片和缩略图
  渲染会被协作取消。
- PPTX 形状、文本和表格渲染会在有界时间片之间主动让出主线程；XML、关系、
  幻灯片上下文和二进制缓存均有固定容量上限。
- 重新加载、切换或关闭演示文稿时也会释放生成的演示文稿资源。
- XLSX 工作表使用最多 2,500 个单元格的挂载上限和有限行列 overscan；
  冻结窗格保持可见，但不会实例化完整工作表。
- 工作表与共享字符串 XML 会分片解压和校验；加载过程报告进度，稠密工作表
  不保留完整 `sheetData` XML，并可在分片和行之间取消解析。
- 工作表解析、切换、工作簿级搜索、摘要收集和计划中的网格渲染都可取消；
  包缓存、挂载绘图、图表抽样点和图片 Blob URL 均有固定上限，并在重新加载、
  切换工作表/文件和关闭视图时释放。
- Word 内容会先渲染到临时缓冲区，再替换可见预览。
- 长文档会分片提交渲染页面并生成导航，让界面可以在批次之间更新。
- 长文档预览会推迟绘制尚未接近可视区域的页面。
- 内嵌图片使用懒加载、异步解码和可回收 Blob URL，不再长期保存 base64
  数据 URL。
- 插件会跟踪当前已渲染的文件状态，避免不必要的重复渲染。
- DOCX 渲染后处理会在一次遍历中收集图片、页数、大纲、Blob URL 和可搜索
  文本。
- DOCX 每次渲染只建立一次可复用文本索引，并使用 CSS Highlight，不再改写
  文档 DOM；阅读状态按动画帧合并，未变化状态不会重复写入。
- 适配宽度只切换 CSS 状态，不会重新渲染文档。
- 开发构建会在开发者控制台记录 Word 文件读取、渲染、DOM 提交、大纲和预览
  总耗时，以及 PPTX 渲染耗时、对象数量、资源和字体指标。
